Integration roadmap

One source of truth, every surface. BEACON keeps a live, PMS-synced model of the building — every unit, status, and date. The interface travels to wherever the agent is standing: a browser today, the lens of their glasses next, and full spatial walkthroughs after that.

Phase 1 · Shipping now

Web HUD + true in-lens app

This demo, plus BEACON GLASS: since May 2026, Meta's Wearables Device Access Toolkit runs third-party web apps directly on Ray-Ban Display — a 600×600 in-lens viewport driven by Neural Band gestures. BEACON GLASS is built and loads on the glasses in developer mode today.

Status: built — web HUD + in-lens app (dev preview, ≤100 testers)
Phase 2 · Next

Public rollout + voice

Meta's open publishing — expected later in 2026 — takes BEACON GLASS from developer preview to any agent's glasses, no tester list. And when Meta exposes voice and Meta AI to third-party display apps, the prospect's own words drive the lens directly.

Status: gated on Meta open publishing — app already built
Phase 3 · Later

Holo table + VR walkthrough

The same building model, projected: a command-table 3D view of the tower for the leasing office, and a Quest walkthrough of the prospect's exact unit — not a model unit, theirs — before it's even vacant.

Status: concept — same data spine
